博客上线：重新开始写字

这是本博客的第一篇文章。在人人都在刷短视频、发动态的 2026 年，我决定反过来，搭一个自己的博客，重新开始长篇幅地写字。

为什么要搭博客

理由其实很朴素：输出倒逼输入。学的东西如果不写下来，过两个月就只剩一个模糊的印象；踩过的坑如果不记录，下次大概率原样再踩一遍。笔记软件里的东西是写给自己的，而博客是公开的——想到「有人可能会看到」，写字时就会多一分认真。

所谓学习，就是把别人的东西嚼碎了讲清楚给自己听；所谓掌握，就是再讲清楚给别人听。

为什么不用框架

现在搭博客太方便了：Hexo、Hugo、Astro 一行命令就能起一个。但我最后选择了纯手写 HTML 和 CSS，理由有三：

  • 没有依赖：不装 Node、不跑构建，双击 index.html 就能看，部署到任何静态托管上都行；
  • 完全可控：每一行排版都是自己写的，想改哪里就改哪里，顺便把 CSS 练熟；
  • 够用就好：一个个人博客需要的不过是文章、归档、标签和关于页，手写完全撑得住。

这里会写什么

  • 技术笔记：Java、Spring、数据库这些后端基础，学明白一块写一块；
  • 项目复盘：比如正在做的 QQ 群「人设」Agent，把设计决策和踩坑都摊开来讲；
  • 生活随笔：月度小结、读书笔记，给生活留个存档。

正文中可以有行内代码、链接，以及一段真正在驱动这个网站的代码——右上角那个深色模式按钮，背后就是这十来行 JavaScript：

// js/main.js —— 深色模式切换
const toggle = document.getElementById('theme-toggle');

toggle.addEventListener('click', () => {
  const next = document.documentElement.dataset.theme === 'dark'
    ? 'light'
    : 'dark';
  document.documentElement.dataset.theme = next;
  localStorage.setItem('theme', next);
});

写给自己
