# 吴子航的博客

纯手写的静态博客：零框架、零构建、零依赖，双击 `index.html` 即可浏览，也可以原样部署到任何静态托管。

v4「太阳系」主题：星海粒子背景 + 3D 太阳系 + 漂浮/飞行模式，玻璃拟态卡片 + 渐变强调色，
衬线体「Blog」辉光字标，支持深浅双主题。

**排版规范**（参照 2026 优秀博客实践）：正文 17px / 行高 1.8 / 中文加宽字距；
首篇文章渐变描边精选位；文章页顶部渐变阅读进度条；
页脚为「渐变线 + 导航 + 版权」的居中锁定组件（不受宽屏左移影响）。

## 太阳系模型（背景，Three.js 真 3D）

`js/solar3d.js` + 本地化的 `lib/three.min.js`（r147，无需网络）：真 3D 球体、
**NASA 数据基准的真实贴图**（`textures/` 目录，Solar System Scope 2K 等距圆柱图，
CC-BY-4.0；加载失败自动回退程序化贴图）、**真实自转轴倾角**（天王星 97.8° 躺着转、
金星 177.4° 逆行）、自转、太阳点光源晨昏线、土星三重环带、地月系统（月球也是真实贴图），
相机随鼠标视差偏移并按视口宽度自动取距（窄屏也能看到完整海王星轨道）。

**质量引力系统**（核心玩法）：

- 每颗行星有质量（地球 = 1）。**水星 / 金星 / 地球 / 火星可以抓起来拖拽**（带惯性缓动跟随）；
  木星 / 土星 / 天王星 / 海王星质量太大拽不动，只能拉出一点形变，松手弹回
- 松手后带着甩出初速进入「太阳 + 全体行星」的引力场做惯性运动
  （GM 与质量成正比，木星能明显捕获碎块；能看到引力弹弓、椭圆轨道、坠日）
- **碰撞破碎分级**：撞上太阳或行星的天体碎成 **1-2 个大块 + 2-3 个中块 + 4-6 个渣渣**，
  全部是不规则岩石块（顶点位移的二十面体，flatShading 棱角感），
  从碰撞面外侧弹出并继承切向速度形成溅射弧线；碎块撞上天体被吞并，飞出边界消失
- **碎块同样可抓取拖拽**（隐形放大拾取球，好点中），松手带速度回到引力场
- **还原按钮**（导航栏 ↺）：一切恢复初始轨道、清空碎块
- 拖拽期间自动禁用文字选中（`body.no-select`），不会误选页面文字；
  文章正文与关于页正文保留可复制

## 飞行模式（第一人称飞船）

右下角「飞行模式」按钮（或 ESC 退出）进入飞船驾驶舱，在 3D 太阳系里自由飞行：

- **W/S 前后、A/D 侧移**（带惯性加速与阻尼），**SHIFT** 加速；
- **按住拖拽转向**，俯仰限制 ±77°，不会钻进太阳（会被弹开），飞太远会被拉回；
- **驾驶舱 HUD**：四角舱体支柱、舱玻璃斜向反光（转向时高光微移）、
  底部控制台含圆形姿态仪（天地随俯仰移动）、SPD/HDG 数字仪表、
  航向刻度条（随转向滚动）、竖直推力条（随油门升降）、中央准星。

## 页面布局

**首页**是「太空站」：宽屏时正文靠左，3D 太阳系在右侧开阔区（含全部引力玩法与飞行模式），
开启漂浮/飞行模式时模型自动居中。**内容页（归档/标签/关于/文章）回归专注阅读**：
不加载 3D 太阳系（省 600KB），排版居中，背景只保留调暗的安静星场，文章是绝对主角。
顶栏在所有页面为左右分布：Blog 字标在左上，导航与按钮贴右上角（内容页无还原/飞行按钮）。

## 漂浮模式

首页和归档页右下角有「漂浮模式」按钮。开启后文章卡片脱离文档流，
像星体一样在页面上自由漂浮：缓慢漂移、轻微自转、边界软反弹、卡片之间弹性碰撞，
鼠标是斥力场——靠近时卡片会被推开；**卡片可以抓起来拖拽，松手带惯性甩出**，
轻点卡片才会打开文章。卡片初始贴屏幕两侧分布、隐藏摘要，中央留给太阳系背景。
再次点击按钮恢复原样。物理实现为圆形近似碰撞 + 法向冲量（恢复系数 0.75）。

## 星海粒子背景

每个页面 `<body>` 开头有一个 `<canvas id="bg-canvas">`，由 `js/background.js` 驱动：

- **星场**：星点缓慢漂移、闪烁，彼此靠近时出现星座连线；每 6–14 秒随机划过一颗流星；
- **视差景深**：每颗星有深度值，鼠标移动时整片星空近大远小地漂移；
- **鼠标交互**：光标周围 140px 内的星点被推开，200px 内的星点拉出引力连线，光标本体带脉冲光环；
- **点击星尘**：点击页面任意处，爆开一圈星尘与双层冲击波，并推开附近星点；
- **光标轨迹**：快速移动鼠标时会拖出细碎星屑（暗色模式下叠加发光）；
- **滚动星风**：快速滚动页面时，星场顺着滚动方向流动；
- **主题切换涟漪**：点右上角切换按钮时，从按钮处荡开一圈粒子涟漪；
- **卡片 3D 悬停**：文章卡片跟随鼠标轻微倾斜（js/main.js，仅桌面精确指针）；
- **眉行解码动画**：首页「深空站已上线」以乱码落定的方式出现（js/main.js）。

**性能与无障碍**：星点数量随屏幕面积缩放（50–170 颗）、星屑总量封顶 140；标签页隐藏时暂停；
系统开启「减少动态效果」时只渲染静态星空、禁用全部交互特效与漂浮模式。

想调粒子密度、连线距离、流星频率、点击星尘数量，改 `background.js` 顶部的 `CONFIG` 即可。

## 科学模式与鼠标模式（调节台）

调节台顶部两组分段控件：

- **渲染模式**：实体 / 线框 / 点云——点云模式行星化作粒子云，可看穿球体观察轨道
- **鼠标模式**：
  - **选中模式**（默认）：点击 / 拖拽行星与碎块
  - **自由模式**：无法选中星体；**拖拽旋转视角**（抓星空手感），
    **滚轮缩放**（深度 10–1500，且**缩放指向光标处**——对准行星往里滚就能凑到它表面近旁）；
    与轨道视角平滑混合过渡

## AI 副驾驶 Agent（仅首页）

顶部 ✦ 按钮打开底部指令胶囊。这是一个小型 Agent：
**规划器**（多步任务拆分）→ **记忆**（上下文目标）→ **工具层**（飞行指令 + 系统工具）→ **执行器**（顺序队列）→ **反馈**（阶段/距离/速度实时回显）。

- **多步任务**：「先去木星，然后借力去海王星，绕两圈」自动拆成 3 步顺序执行；
- **上下文记忆**：「再去土星」沿用上一目标；中文圈数（两圈/三圈）可解析；
- **遥测问答**：「现在速度多少」「在哪」「距离木星多远」实时回答；
- **系统工具**：「还原太阳系」「切换线框/点云模式」「时间快进 / 慢放 / ×2.5」「切自由模式」；
- **「停止」**清空队列切回手动；手动转向或 WASD 也会立即中止队列。

Agent 的「文本 → 结构化 JSON」解析层目前是本地意图识别（离线零延迟），
接口稳定——接真 LLM 只需替换 `copilot.js` 的 `parseOne()`；
接真 RL 策略只需替换 `solar3d.js` 的 `pilotStep` 决策层，Agent 骨架原样复用。

## 太阳系调节台（仅首页）

顶部导航的滑杆按钮打开侧滑「调节台」，实时调节全部可调参数（改动即时生效）：

- **时间与运动**：时间流速（公转/自转倍率 0.2–4）、行星大小、太阳大小、轨道线亮度、视角视差
- **引力与拖拽**：太阳引力、行星引力系数、甩出限速、可拖拽质量上限（调满可以拽木星）
- **星场**：星点密度、连线距离、流星间隔、点击星尘数量

底部「恢复默认」一键回滚全部参数，「还原太阳系」复位天体与碎块。
参数定义在 `solar3d.js` 的 `PARAMS`（引擎每帧实时读取），面板为 `js/tune-panel.js`。

## 怎么写一篇新文章

1. 复制 `posts/` 里任意一篇作为模板；
2. 改 `<title>`、`<meta name="description">`、日期、标题、正文；
3. 正文写在 `<div class="post-content">` 里，标题用 h2/h3，代码块写法：
   ```html
   <pre><code class="language-java">...</code></pre>
   ```
   支持 java / python / yaml / sql / js，自动做轻量高亮（注意：代码里的 `<` 要写成 `&lt;`，`>` 写成 `&gt;`）；
4. 在 `index.html` 首页列表、`archive.html` 归档、`tags.html` 对应标签下各加一条链接；新标签要在 `tags.html` 顶部索引里也加一项；
5. 如果不是最新的文章，把前后文章页脚的「上一篇 / 下一篇」链接顺一遍。

## 怎么个性化

- **换主题色**：`css/style.css` 顶部 `--accent` 改一个颜色即可，深浅两套主题都有对应变量；
- **改名字/简介**：各页面的 `<title>`、首页 hero、`about.html`；
- **替换占位联系方式**：`about.html` 里的 GitHub 和邮箱目前是占位符；
- **favicon**：`favicon.svg` 里的「航」字和配色可自行调整。

## 怎么发布到网上

任选一种，都是免费静态托管：

- **GitHub Pages**：把 `blog/` 里的文件推到一个仓库（如 `blog`），Settings → Pages → 选择 `main` 分支根目录，几分钟后访问 `https://<用户名>.github.io/blog/`；
- **Vercel / Netlify**：导入仓库，构建命令留空、输出目录填根目录即可；
- **云服务器**：把整个目录扔给 Nginx 做静态站点根目录。
